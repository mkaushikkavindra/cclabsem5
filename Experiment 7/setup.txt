Hadoop Single Node Cluster – Setup Procedure
=============================================

AIM:
To set up a one-node Hadoop cluster using Hadoop 2.7.0 and Java 1.7 on Ubuntu Linux.

ENVIRONMENT:
  Host OS  : Windows (VirtualBox)
  Guest OS : Ubuntu Linux (inside VM)
  Hadoop   : 2.7.0
  Java     : OpenJDK 1.7

========================================================
STEP 1: UPDATE PACKAGE LISTS
========================================================

$ sudo apt-get update

========================================================
STEP 2: INSTALL JAVA (JDK AND JRE)
========================================================

Install OpenJDK 7:
$ sudo apt-get install openjdk-7-jdk
$ sudo apt-get install openjdk-7-jre

Verify Java installation:
$ java -version

Expected output:
  java version "1.7.0_79"
  OpenJDK Runtime Environment (IcedTea 2.5.6) (7u79-2.5.6-0ubuntu1.14.04.1)
  OpenJDK 64-Bit Server VM (build 24.79-b02, mixed mode)

Find Java installation path:
$ readlink -f /usr/bin/java

Example output:
  /usr/lib/jvm/java-7-openjdk-amd64/jre/bin/java

Note JAVA_HOME as:
  /usr/lib/jvm/java-7-openjdk-amd64

========================================================
STEP 3: INSTALL SSH SERVER
========================================================

$ apt-get install openssh-server

Generate SSH key pair (passwordless SSH for Hadoop):
$ ssh-keygen -t rsa -P "" -f ~/.ssh/id_rsa

Add the public key to authorized keys:
$ cat ~/.ssh/id_rsa.pub >> ~/.ssh/authorized_keys

Test SSH connection:
$ ssh localhost

========================================================
STEP 4: CREATE HADOOP USER AND GROUP
========================================================

Add a dedicated group for Hadoop:
$ sudo addgroup hadoop

Add a dedicated user in the hadoop group:
$ sudo adduser --ingroup hadoop hadoop

Switch to the hadoop user:
$ su - hadoop

========================================================
STEP 5: DOWNLOAD AND EXTRACT HADOOP 2.7.0
========================================================

Download (or transfer) the Hadoop 2.7.0 archive.

Extract to /usr/local/lib/:
$ sudo tar -xzvf hadoop-2.7.0.tar.gz -C /usr/local/lib/

Change ownership to the hadoop user:
$ sudo chown -R hadoop:hadoop /usr/local/lib/hadoop-2.7.0

========================================================
STEP 6: CREATE HDFS DIRECTORIES
========================================================

Create NameNode directory:
$ sudo mkdir -p /var/lib/hadoop/hdfs/namenode

Create DataNode directory:
$ sudo mkdir -p /var/lib/hadoop/hdfs/datanode

Set permissions:
$ sudo chown -R hadoop /var/lib/hadoop

========================================================
STEP 7: CONFIGURE ENVIRONMENT VARIABLES
========================================================

Edit the .bashrc or /etc/environment file:
$ nano ~/.bashrc

Add the following lines:

# Java
export JAVA_HOME=/usr/lib/jvm/java-7-openjdk-amd64

# Hadoop
export HADOOP_INSTALL=/usr/local/lib/hadoop-2.7.0
export HADOOP_HOME=$HADOOP_INSTALL
export HADOOP_MAPRED_HOME=$HADOOP_INSTALL
export HADOOP_COMMON_HOME=$HADOOP_INSTALL
export HADOOP_HDFS_HOME=$HADOOP_INSTALL
export YARN_HOME=$HADOOP_INSTALL
export HADOOP_COMMON_LIB_NATIVE_DIR=$HADOOP_INSTALL/lib/native

# PATH
export PATH=$PATH:$HADOOP_INSTALL/sbin:$HADOOP_INSTALL/bin

Apply changes:
$ source ~/.bashrc

Verify:
$ hadoop version

Expected:
  Hadoop 2.7.0

========================================================
STEP 8: CONFIGURE HADOOP XML FILES
========================================================

Location: /usr/local/lib/hadoop-2.7.0/etc/hadoop/

File 1: core-site.xml
----------------------
<configuration>
  <property>
    <name>fs.default.name</name>
    <value>hdfs://localhost:9000</value>
  </property>
</configuration>

File 2: hdfs-site.xml
----------------------
<configuration>
  <property>
    <name>dfs.replication</name>
    <value>1</value>
  </property>
  <property>
    <name>dfs.namenode.name.dir</name>
    <value>file:///var/lib/hadoop/hdfs/namenode</value>
  </property>
  <property>
    <name>dfs.datanode.data.dir</name>
    <value>file:///var/lib/hadoop/hdfs/datanode</value>
  </property>
</configuration>

File 3: mapred-site.xml
------------------------
<configuration>
  <property>
    <name>mapreduce.framework.name</name>
    <value>yarn</value>
  </property>
</configuration>

File 4: yarn-site.xml
----------------------
<configuration>
  <property>
    <name>yarn.nodemanager.aux-services</name>
    <value>mapreduce_shuffle</value>
  </property>
</configuration>

========================================================
STEP 9: FORMAT NAMENODE AND START HADOOP
========================================================

Format NameNode (first time only):
$ hdfs namenode -format

Start HDFS:
$ start-dfs.sh

Start YARN:
$ start-yarn.sh

Verify all services:
$ jps

Expected processes:
  NameNode
  DataNode
  SecondaryNameNode
  ResourceManager
  NodeManager

Access Hadoop Web UI:
  HDFS:  http://localhost:50070/
  YARN:  http://localhost:8088/

========================================================
RESULT
========================================================

Hadoop 2.7.0 single-node cluster setup completed successfully.
HDFS and YARN services are running.
